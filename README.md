RPG de Turnos ⚔️

Este é o meu primeiro projeto em JavaScript, desenvolvido como uma forma de praticar e aplicar os conceitos que estava aprendendo na linguagem.

O projeto consiste em um pequeno RPG de batalha por turnos, no qual o jogador controla um cavaleiro que enfrenta um Goblin. A interface é dividida em duas partes principais: a área superior apresenta os personagens, suas barras de vida e as mensagens referentes ao que está acontecendo durante a batalha; a área inferior disponibiliza as ações que o jogador pode realizar.

🎮 Funcionalidades

O jogador pode escolher entre quatro ações:

⚔️ Atacar — causa uma quantidade aleatória de dano ao Goblin.
❤️ Curar — recupera uma quantidade aleatória de vida.
🛡️ Defender — possui uma chance de bloquear o próximo ataque.
🏃 Fugir — possui uma chance de encerrar a batalha escapando.

O Goblin também possui um sistema de ações próprias, escolhendo aleatoriamente entre atacar, curar e defender, de acordo com sua quantidade de vida.

O jogo também conta com:

Sistema de vida para o jogador e o inimigo.
Barras de vida que são atualizadas durante a batalha.
Sistema de turnos.
Dano e cura com valores aleatórios.
Diferentes imagens para representar as ações dos personagens.
Mensagens informando o resultado de cada ação.
Condições de vitória e derrota.
Bloqueio dos botões quando não é o turno do jogador ou quando a batalha termina.
🛠️ Tecnologias utilizadas
HTML5 — estrutura da interface.
CSS3 — estilização e organização visual.
JavaScript — lógica do jogo, sistema de turnos, ações, vida e interação com a interface.

Funções;
Condicionais (if, else if, else);
Eventos e addEventListener;
Manipulação do DOM;
setTimeout();
Math.random();
Operadores matemáticos;
